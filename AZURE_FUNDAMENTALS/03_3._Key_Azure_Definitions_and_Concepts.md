 # 3. Key Azure Definitions and Concepts (Azure Fundamentals - Beginner Level)

Welcome to the section focusing on essential Azure definitions and concepts! This guide will provide you with a comprehensive understanding of Azure's core components, designed for absolute beginners. By the end of this section, you'll be able to navigate Azure more confidently.

## Azure Subscriptions
An **Azure subscription** is an agreement between Microsoft and the user that determines access to Azure services, resources, and quotas. Each Azure account can have multiple subscriptions, allowing for separate billing, access control, and resource management.

![Azure Subscription Example](https://docs.microsoft.com/en-us/azure/cost-management-billing/manage/overview#:~:text=Each%20subscription%20is%20a%20contractual,resource%20usage%20and%20quotas.)

## Azure Portal
The **Azure Portal** is a web-based interface that provides access to all Azure services. It serves as the central hub for managing resources, monitoring usage, and configuring settings. The portal can be accessed at [portal.azure.com](https://portal.azure.com).

![Azure Portal Screenshot](https://docs.microsoft.com/en-us/azure/azure-portal/media/overview-azure-portal/azure-portal-screenshot.png)

## Resource Groups
**Resource Groups** are logical containers that hold related resources for an Azure solution. They help in managing resources by deploying, updating, and deleting them together as a single unit. A resource group can contain resources of different types such as virtual machines, storage accounts, and databases.

![Azure Resource Group Example](https://docs.microsoft.com/en-us/azure/azure-resource-manager/management/overview#:~:text=A%20resource%20group%20is%20a,and%20deleting%20them%20together.)

## Azure Active Directory (Azure AD)
**Azure Active Directory (Azure AD)** is Microsoft's cloud-based identity and access management service. It provides a secure way to manage user authentication and authorization for applications, services, and devices. With Azure AD, you can create users, groups, and manage permissions for your entire organization.

![Azure Active Directory Screenshot](https://docs.microsoft.com/en-us/azure/active-directory/media/whatis-azure-active-directory/100.png)

## Examples and Real-World Applications
Let's look at a simple example to illustrate how these concepts work together:

Imagine you are starting a new business and want to use Azure to host your website, store customer data, and collaborate with team members. You would create an **Azure subscription** to access Azure services. Within this subscription, you'd create a **Resource Group** that contains the necessary resources such as a virtual machine (for hosting the website), storage accounts (for storing customer data), and an Azure AD instance (to manage user identities). Finally, you can use the **Azure Portal** to deploy, monitor, and update these resources.
