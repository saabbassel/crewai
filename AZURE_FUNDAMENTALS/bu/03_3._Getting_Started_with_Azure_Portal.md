 ## 3. Getting Started with Azure Portal

Welcome to the world of Azure! In this section, we'll guide you through navigating the web-based management interface for configuring Azure services - the Azure Portal. By the end of this tutorial, you'll have a solid understanding of how to use this essential tool to manage your Azure resources.

### What is the Azure Portal?

The Azure Portal (<https://portal.azure.com>) is a web-based platform for managing and monitoring Azure services. It provides an intuitive interface that allows users to create, configure, and monitor resources in their Azure subscription.

### Navigating the Azure Portal

Upon logging into the Azure Portal, you'll be greeted with the **Home** dashboard, which displays a summary of your Azure resources. To navigate through the portal, use the menu on the left-hand side (known as the **Hub**) and the command bar at the top (the **Search box** and the **Command bar)**.

#### The Hub

The Hub is divided into several sections:

1. **Home:** Displays a summary of your Azure resources, including recent activity, alerts, and quick links to frequently used services.
2. **Resource Groups:** Lists all the resource groups in your subscription. Resource groups help you organize and manage related resources together.
3. **Services:** Provides access to Azure services organized by category (e.g., compute, networking, storage, etc.).
4. **Subscriptions:** Lists all the subscriptions associated with your account. Each subscription represents a separate set of resources and usage quotas.
5. **Resources:** Shows all the individual resources in your subscription.
6. **Recommendations:** Offers suggestions to optimize your Azure resources for better performance and cost savings.
7. **Billing + Cost Management:** Provides insights into your Azure resource consumption and costs.
8. **Notifications:** Displays alerts and notifications about your Azure resources.
9. **Help + Support:** Offers access to Azure documentation, support options, and troubleshooting tools.

#### The Command Bar

The command bar at the top of the Azure Portal contains several useful features:

1. **Search box:** Allows you to quickly find resources or services by entering keywords.
2. **Notifications bell:** Displays alerts, notifications, and messages related to your Azure resources.
3. **Profile icon (head and shoulders):** Opens the user profile menu, where you can view account details, manage subscriptions, access billing information, and more.
4. **Help icon (question mark):** Provides access to Azure documentation, support options, and troubleshooting tools.
5. **Add resource:** Enables you to create new resources in your subscription.
6. **Resource groups:** Allows you to switch between different resource groups in your subscription.
7. **Browse:** Lets you explore Azure services organized by category (e.g., compute, networking, storage, etc.).
8. **Subscriptions:** Enables you to switch between different subscriptions associated with your account.

### Creating Your First Resource in the Azure Portal

To create a new resource in the Azure Portal, follow these steps:

1. In the **Services** section of the Hub, find the service you want to create (e.g., Virtual Machines).
2. Click on the service to open its overview page.
3. Click the **Add** button located at the top of the page.
4. Fill in the required details for your new resource, such as name, size, region, and other configuration settings.
5. Click the **Review + Create** button to review your settings before creating the resource.
6. If everything looks correct, click the **Create** button to deploy the resource.
7. Monitor the progress of the deployment in the notifications center or on the resource's overview page.

### Real-World Application

Let's say you want to create a virtual machine (VM) for testing purposes. First, navigate to the **Compute** section in the Hub and click on **Virtual machines**. Next, click the **Add** button to start the creation process. Fill out the required details, including the VM name, size, region, and other configuration settings. After reviewing your selections, click **Create** to deploy the virtual machine. You can then connect to the VM using Remote Desktop (for Windows VMs) or SSH (for Linux VMs) to perform various tasks.
